# Related work

The requested paper, **“When Machine Unlearning Meets Retrieval-Augmented
Generation (RAG): Keep Secret or Forget Knowledge?”**, is a relevant starting
point, but its authors, identifier, venue, and publication status were not
verified in the available repository session. It must not be cited as a
verified publication until checked against the authors' page, the publisher,
Crossref, or an arXiv record.

The following established sources are useful starting points and should be
checked against the final bibliographic records before submission:

1. **Cao, Y., and Yang, J. (2015). “Towards Making Systems Forget with
   Machine Unlearning.”** 2015 IEEE Symposium on Security and Privacy
   Workshops. DOI/stable search entry:
   <https://doi.org/10.1109/SPW.2015.13>. This introduced an early formal
   framing for machine unlearning.
2. **Lewis, P. et al. (2020). “Retrieval-Augmented Generation for
   Knowledge-Intensive NLP Tasks.”** NeurIPS 2020. Stable URL:
   <https://arxiv.org/abs/2005.11401>. This is the foundational RAG system
   reference for retrieval plus generation.

This project should position itself as a small empirical evaluation of
retrieval-layer deletion and prompt constraints, not as a new proof of
machine unlearning. Complete the unchecked bibliographic verification and
add only sources whose metadata has been confirmed.
